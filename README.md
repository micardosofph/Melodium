# Melodium

O **Melodium** é um aplicativo Android criado para ajudar músicos a praticar, registrar sua evolução e acompanhar sua constância. A versão atual funciona localmente no celular, sem cadastro ou login.

## Baixar o aplicativo

### [⬇️ Baixar Melodium 1.1.0 Preview para Android](https://github.com/micardosofph/Melodium/releases/download/v1.1.0-preview/Melodium-1.1.0-preview.apk)

[Ver detalhes e notas da versão no GitHub](https://github.com/micardosofph/Melodium/releases/tag/v1.1.0-preview)

> Esta é uma versão experimental para testes e demonstrações. Ao instalar o APK, o Android pode pedir autorização para instalar aplicativos desta fonte.

## Funcionalidades

- Práticas com cronômetro e registro manual de sessões anteriores.
- Histórico com tempo total, quantidade de práticas e ofensiva diária.
- Página de progresso baseada nos dados registrados pelo usuário.
- Gravação de vídeos com câmera frontal, nome personalizado e galeria local.
- Diário de evolução com textos e fotos opcionais.
- Metrônomo e afinador integrados.
- Perfil personalizável com nome e foto.
- Guia interativo pelas principais áreas do aplicativo.
- Lembretes diários em horário configurável.
- Dados salvos localmente no aparelho.

## Como instalar no Android

1. Abra o link de download acima pelo celular.
2. Baixe o arquivo `Melodium-1.1.0-preview.apk`.
3. Abra o arquivo baixado.
4. Se o Android solicitar, permita a instalação de aplicativos dessa fonte.
5. Toque em **Instalar** e depois em **Abrir**.

Depois da instalação, o aplicativo abre diretamente no celular, sem computador, QR Code ou servidor de desenvolvimento.

## Desenvolvimento

O aplicativo mobile está em [`frontend/MelodiumMobile`](frontend/MelodiumMobile) e foi desenvolvido com React Native e Expo.
